# Contract v1 (implementation baseline)

Approved scope: Codex project coordination; DSH Flash-default bounded coding/investigation/review/integration; explicit model routing and skill layers; structured task handoff; risk-based understanding gate; durable task/attempt identity, idempotency, bounded waits, recovery and cancellation; isolated Git workspaces, review tied to exact commit and controlled integration; owned-session retention/cleanup. No automatic model fallback, arbitrary-user-session adoption, credential disclosure, or recursive delegation.

Language/runtime: Node 24 ESM and node:test, built-ins only. Exports below are stable. Throw Error with `.code` for domain failures. Objects crossing boundaries are JSON-serializable. Timestamps are integer epoch milliseconds. All public inputs are untrusted and validated. State is host-owned; model assertions never supply execution evidence.

## TaskPacket
Required: `schemaVersion:1`, `idempotencyKey` (nonblank <=200), `revision` (positive integer), `projectId`, `title`, `objective`, `cwd` (absolute existing directory), `role` (`investigate|implement|review|integrate`), `acceptance` (nonempty string array), `scope` `{readRoots:string[],writeRoots:string[],allowedTools:string[],allowShell:boolean,allowNetwork:boolean,allowDelegation:false}`, `materials` array of `{path?,text?,version?,sha256?}`, `contractVersion` string.
Optional: `parentTaskId`, `dependencies:string[]`, `model` `{provider,model,reasoningEffort?}`, `budget` `{timeoutMs,maxToolCalls,maxOutputChars}`, `understandingRequired:boolean`, `workspace` `{repository,baseRef,branchName?}`, `retention` `{successDays,failureDays}`, `metadata` plain object. Missing model uses Flash default. Missing budgets default to 600000ms, 100 calls, 200000 chars; these are requested constraints and MUST NOT be reported hard enforced without corresponding runtime support.

## Models / context module (src/models.mjs and src/context.mjs)
`resolveModel({user,task,project,defaults,catalog,profiles})` returns `{provider,model,reasoningEffort?,profileId,profileVersion,skillIds:string[]}`. First defined complete route wins user > task > project > defaults (Flash default if absent); reject incomplete route/unknown route/unsupported explicitly provided effort when catalog advertises efforts. catalog is array `{provider,models:[{id,reasoningEfforts?:string[]}]}`. profiles array `{id,version,provider,model,skillIds?:string[],roles?:string[]}`. No silent fallback. Return detached values.
`buildPrompt(packet,{model,skills=[]}={})` returns text preserving scope, sources as untrusted materials, precise acceptance, fact/inference/unknown distinctions, no recursive delegation, owner coordination; understanding gate instructs return understanding/assumptions/actions/missing without executing. Skills are array `{id,version,text,layer:'common'|'role'|'model'}` ordered layers; cannot expand task authorization. `buildExecutionPrompt(packet,understanding)` composes authorized execution message.

## Workspace module (src/workspaces.mjs)
`WorkspaceManager({root,git='git'})` with async `create({taskId,repository,baseRef,branchName?})` -> `{taskId,path,branch,baseCommit,repository}`, `inspect(workspace)` -> `{head,dirty,changedPaths}`, `review(workspace,{head,contractVersion,passed,checks})` -> immutable review record. `integrate(workspace,{targetRepository,review,contractVersion,checks=[]})`: refuse dirty source/target, mismatched head/contract, target not equal base (caller must rebase and re-review), failed review. Run supplied checks as `{command,args}` without shell in source and target as appropriate; use fast-forward-only merge after verification; if target check fails do not misreport accepted. Return exact head/check evidence. `remove(workspace,{artifactState,pinned=false})`: only manager-owned path inside root, no dirty/uncollected changes; artifactState `merged|preserved|discarded` required; native git worktree remove only, never arbitrary recursive deletion. Implement ownership persistence under root. No caller-controlled raw command strings.

## Retention policy module (src/retention-policy.mjs) - isolated comparison
Pure export `evaluateRetention(task, policy, now)` -> `{eligible:boolean,reasons:string[],eligibleAt:number|null}`. No mutation, I/O, clock reads. policy `{ownerId,successDays:7,failureDays:30}`. Owned task requires exact nonblank `task.ownerId===policy.ownerId`, task `origin==='codex-bridge'`, nonblank `task.id`; permitted terminal states `completed|failed|cancelled`; integer nonnegative `endedAt<=now`; `resultCollected===true`; `pinned!==true`; `stopConfirmed===true`; `activeJobs===0`; `artifactState` one of `none|merged|preserved|discarded`. Unknown/in-flight/unconfirmed/malformed must fail closed. Duration days finite nonnegative; now integer nonnegative. completed uses successDays, others failureDays; expiry inclusive. Reasons are stable machine strings, include all applicable blockers in this fixed order: invalid_policy, invalid_time, foreign_owner, invalid_identity, nonterminal, invalid_end, uncollected, pinned, stop_unconfirmed, active_jobs, artifacts_unresolved, retention_pending. `eligibleAt` = valid endedAt + valid retention duration (safe integer) only when status, endedAt, policy and now valid, otherwise null. Invalid/overflow policy duration -> invalid_policy. Evaluate nonobjects as empty objects. `activeJobs` MUST equal numeric 0 (no coercion). Missing artifactState blocks. Invalid result collection / stop confirmation values block. For malformed now, invalid_end only when endedAt itself malformed; future-ended comparison applies only if now valid. Unknown status => nonterminal and eligibleAt null. Empty/missing policy ownerId => invalid_policy AND foreign_owner. Whitespace ids invalid. pinned false/absent accepted; nonboolean supplied pinned => pinned (fail closed). Unknown extra fields ignored.

## DSH adapter seam (coordinator / adapter worker)
Runtime adapter exposes async `capabilities()`, `models()`, `start(task,{onEvent,onResult})`, `continue(task,understanding,{onEvent,onResult})`, `cancel(task)`, `inspect(task)`, `cleanup(task)`. All return JSON objects; start yields `{sessionId,requestId,effectiveModel,effectivePolicy}`. Events contain type, timestamp, taskId, revision, attemptId, seq when available. Cancellation returns `{accepted,stopConfirmed,remaining:[]}`; host cancel alone is never confirmation. Runtime worker must document actual installed DSH hook/API support, and fail closed if requested scope cannot be enforced. Never fake hidden/cleanup support.

## Coordination and tests
Root owns contracts, task store, orchestration, HTTP/MCP and packaging. Workers own only explicitly assigned module/tests. Every test invocation must finish within a bounded task budget. No unrelated live-host restarts. Benchmark branches have the SAME task, code baseline and acceptance tests; do not inspect other candidate implementations. First-pass and repair results are separate. Verify actual model/effort from runtime records. No general model ranking from one module.

## Long-task supervisor (`packet.project`) — long-supervisor-first-edition-v1
Optional additive grant on `bridge_submit` (advertised in the packet schema; reported by `bridge_capabilities.supervisorProjects`). Absent => the historical single bounded task, byte-identical. Host policy `supervisorProjects.enabled` defaults to `false`; when it is not true a `project` packet is refused (`PROJECT_UNSUPPORTED` / `adapter/project-unsupported`) before any task, session or worktree exists. Host caps (16 workers, 2 repair attempts, 64 starts/retries, 15 reserved slots, 86400000 ms) are ceilings: a larger request is refused (`PROJECT_HOST_CAP`), never clamped.

`src/contracts.mjs` validates and normalizes the block: `{maxWorkers,maxConcurrentWorkers,maxRepairAttempts<=2,maxTotalRetries,maxWorkerStarts,maxTotalToolCalls,timeoutMs,reserveSlots,workerScope{readRoots,writeRoots,allowedTools,allowNetwork,budgets?},workspace{repository,baseRef}?}`. A project packet must declare `scope.writeRoots: []` and must not grant `scope.childSessions`/`scope.backgroundJobs`; `understandingRequired` is refused; with `workspace`, every worker root and `cwd` must stay inside the repository so a per-writer worktree really isolates them.

`src/long-task.mjs` owns the runtime: `createProjectRecord` is persisted WITH the task before any dispatch; `resolveProjectGrant` enforces host caps; `attenuateWorkerRequest` refuses (never clamps) any worker widening and always fixes the worker route to the project's inherited model; `aggregateProject` is the pure completion/retry/failure gate (`attempt.retryBlocked` = exhausted; a controller cancellation is never retryable); `projectCallbackEventId` binds a stable identity to (task, attempt, outcome class, aggregate). Statuses: `planning|frozen|dispatching|completed|failed|blocked|cancelled`, plus the non-terminal task status `supervising` while a project waits between rounds. Only verified stopped owned work may produce a terminal `completed`/clean `failed`; unverified work => `project.status:'blocked'`, task status `unknown`, `stopConfirmed:false`, reservations held, no redispatch. `admitProject`, called once by `src/service.mjs` immediately after the project task is persisted and before any dispatch, arms the single LIVE project deadline from `project.createdAt` and clamps the supervisor's EFFECTIVE packet budget to the grant while `task.packet` and the stored request hash stay immutable (a later dispatch clamps the effective timeout to the remaining project wall time). The shared tool cap uses one canonical accounting counted once (supervisor observed spend + each stop-proven attempt's actual spend + each unverified attempt's full granted allowance); missing/unreadable receipts keep their full allowance, a temporary reservation makes a queued worker wait rather than fail, and no clean completion/failure/cancellation is recorded without supervisor-round AND every-owned-attempt stop proof. `src/dsh-adapter.mjs` registers six `dsh_supervisor_*` tools into the authorized supervisor's own scoped layer only when the grant is present, admits them by grant (naming them in `allowedTools` is refused), and keeps them out of every worker/child. `src/supervisor.mjs` adds the durable `notifyProjectOutcome` (one event per outcome class; a serious issue never claims a stop). `src/service.mjs` releases only the supervisor's own model reservation at a positively stopped round, drives the runtime from settlement hooks, and branches project tasks in `finish/cancel/recover/reconcile/wait`. Shutdown closes the runtime before the outbox. Evidence: `test/long-task.test.mjs`, the additions to `test/dsh-adapter.test.mjs`, and the real offline `scripts/smoke-supervisor.mjs` with `test/fixtures/supervisor-provider.mjs`.
